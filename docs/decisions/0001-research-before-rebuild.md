# Start fresh with research before rebuilding

Date: 2026-11-01

Status: clarified by [Research-informed redesign](0003-research-informed-redesign.md), following the intervening [original-site baseline decision](0002-original-site-workflow-baseline.md).

The research-first and fresh implementation directions remain in effect. Decision 0002 briefly treated the original as a content/workflow baseline. Decision 0003 records the owner's clarification: use it as contextual evidence while redesigning through all three research tracks. It is not a required feature inventory or accepted workflow.

## Context

Earlier iterations alternated between excessive interaction and excessive simplification. The owner reported missing data and graphs, too many clicks and insufficient source controls in the header. The owner then requested a fresh start, followed by research into what pilots need, existing aviation interfaces and suitable data sources.

## Decision

Use this repository as the new project foundation. Preserve confirmed requirements and research in documentation before selecting the implementation stack or importing application code. Prior layouts and the original Google Site are historical context, not a required feature inventory or an accepted design.

## Consequences

The first repository setup contains documentation, agent guidance and documentation validation. Product recommendations remain labelled as proposals until the corresponding decision is made. Future implementation should prove the data path and validate the primary workflow before expanding the interface.

The fresh start does not discard the owner's requirements for substantial graphs, working data, prominent source selection and low interaction cost.
